# Website runbook — verification gates (Casa Escondida example)

| # | Stage | Verify gate |
|----|-------|-------------|
| S0 | Ingest | all declared sources resolved; manifest complete |
| S1 | Research / RAG | every required fact has a cited source; no unsupported claims |
| S2 | Architecture | every required page/section is planned |
| S3 | Content | each section has copy; no placeholder/lorem; brand voice applied |
| S4 | Assemble / build | build succeeds; output dir populated |
| S5 | Site QA | no broken internal links; required meta/SEO present |
| S6 | Deploy (gated) | deployment reachable; smoke check on key routes passes |
